# 食日 · 饮食与体重日记

中文、移动优先的私人营养与体重记录网站。

**网站地址：[食日](https://shiri-private-nutrition.haoyun963.chatgpt.site)**  
网站需要所有者使用 ChatGPT 登录。这个仓库公开源码；个人饮食、体重、照片和资料不公开。

## 功能

- 每日摄入中心估算与上下限，和你设定的参考目标比较。
- 餐食照片日记；可编辑份量、用油、估算、置信度与来源。
- 来源地区、核查日期、标示份量、实际食用比例与额外配料单独保留。
- 每日原始体重与 7 日平均，支持 7 / 30 天视图和可读数据表，显示样本数，缺失日期不补造称重。
- 记录完整度、历史、JSON 导入、导出与备份恢复。
- 保存失败保留当前表单；离开或刷新前提示未保存输入，跨设备版本冲突会阻止覆盖。
- 日期快捷切换、照片保存前预览、更大的手机文字与触控目标。
- 导入先核对再确认：重复照片备份沿用原引用，较早记录不覆盖新记录；完整度支持独立更新时间。
- Mifflin–St Jeor 静息能量消耗估算；不把静息代谢当作摄入目标。
- 目标按生效日期保留版本，不根据一天的体重或漏记自动调整。

## 存储与聊天更新

使用 Sites 的 D1 保存结构化记录，R2 保存照片。照片经所有者身份校验后读取，浏览器缓存不是健康记录的唯一来源。匿名、身份缺失或其他所有者请求被拒绝。

用户在聊天中请求更新时，dot 可维护私人 Sites 项目中的服务端快照并发布更新。下一次登录打开或刷新网站时，快照合并入记录库。稳定 ID、更新时间、请求回执与版本比较避免重复和覆盖。完整度可附加 `completenessUpdatedAt` 的日期 → ISO 时间映射；较早或未带时间的状态不会覆盖已有状态，旧格式仍可读。聊天批次冲突会显示待合并提示，并保留现有日记访问。

**此公开仓库是脱敏源码副本，不是私人 Sites 仓库的自动镜像。** 公开版的 `lib/journal/chat-snapshot.json` 始终为空。实际聊天记录、照片、快照、初始化资料、运行时密钥及历史修订只能留在私人 Sites 项目。不要把私人更新提交到这里。

`/mcp` 提供可选的 `get_journal` 与 `upsert_entries` 接口，使用 Sites 管理的身份认证。源码发布不代表已经连接某个聊天插件，也没有自动监听或定时更新。

## 本地开发与验证

需要 Node.js 22.13 或更高版本。

```sh
npm install
npm run dev
npm test
npx tsc --noEmit
npm run build
```

生成数据库迁移使用 `npm run db:generate`。迁移不含健康种子数据。生产数据库由 Sites 部署应用生成的迁移，运行时不创建表。

`.openai/hosting.json` 仅保留绑定模板，没有私人项目 ID。实际 OWNER_EMAIL 和可选 INITIAL_JOURNAL 在自己的 Sites 项目中配置为私有运行时值。请勿提交 `.env` 或真实健康资料。

## 当前验证范围

类型检查和 Worker 构建通过。18 项离线测试与 SQLite 检查覆盖保存失败保留输入、嵌套保存锁恢复、重复照片导入、聊天快照冲突保持日记可用、照片 ID 不可覆盖、日期/时区/夏令时、计算边界及所有者权限。新版没有完成真实浏览器和托管登录、照片上传的端到端检查，不能把离线结果视为这些流程已验证。

删除当前条目不会自动清除历史修订及未引用照片；尚未实现永久清除界面。

## 科学与来源

区间来自份量、油和配料的具体假设，不是固定误差百分比或统计置信区间。空白记录不计作零摄入，单日体重变化不判断脂肪变化。
